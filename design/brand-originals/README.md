# Official BottleUp brand assets

Supplied Illustrator sources are retained unchanged here. The PDF-compatible artwork was exported as vector paths, with artboard whitespace trimmed and white knockout shapes made transparent. No logo shapes or typography were redrawn.

Web exports live in `bottle-up-mvp/public/brand/`:
- `wordmark.svg`: horizontal logo and tagline for navigation and dashboard headers.
- `wordmark-light.svg`: cream version for the green authentication background.
- `full.svg`: stacked full logo in the landing footer.
- `mark.svg`: standalone B mark; also used for the browser favicon and Apple touch icon.

Original green: `#006838`. Light variant: `#f7f4ec`. Original proportions are retained. UI navigation icons remain the existing KingFTP icon family.

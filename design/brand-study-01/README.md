# BottleUp — brand study 01

Concept: Good things come around.

A warm, practical neighbourhood recycling service. Show the exchange between residents and collectors, make verified rewards clear, and give the brand a recognizable bottle/up motif.

## Deliverables
- brand-board.png — exploratory wordmark, symbol, colours and physical applications.
- pickup-hero.png — standalone illustration with room on the left for live website text.
- product-concept.png — desktop landing page and mobile dashboard visual concept.
- prompts.json — original generation prompts, in brand board / hero / product order.
- board-revision-prompt.txt — targeted correction to improve brand-board legibility.

Generated using the built-in image generation tool. These are raster concept studies, not implemented screens or final vector logo assets. The existing application is unchanged.

## Research and interpretation
- [Wecyclers](https://wecyclers.com/about/): Nigerian rewards-for-recycling service, points based on collected weight. Implication for BottleUp: communicate practical household value and collection clearly.
- [Bower / OKTO](https://okto.co/work/bower/): identity designed to make recycling part of everyday life, using a recognizable scalable symbol and distinctive lettering. Implication: develop one consistent visual language across app and collection equipment.
- [Grale / Pentagram](https://www.pentagram.com/work/grale): friendly identity with a distinct symbol, custom lettering and a warm palette. Implication: recycling can have expressive colour and memorable branding.

These are research references, not endorsements or partners. Artwork and identity concepts were generated for BottleUp.

## Proposed palette
- Deep ink: #173C32
- Tangerine: #F36B3F
- Bottle green: #278460
- Sky: #BDDBE3
- Paper: #F4F0E5

Use ink on cream for primary reading surfaces. Before implementation, check actual text/background contrast; orange buttons may need dark text. Generated images approximate colours; these tokens are the intended source values.

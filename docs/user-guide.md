# User guide

Use [BottleUp](https://usebottleup.xyz) or a locally configured development server. Create an account and sign in to access your dashboard.

## Schedule a pickup

1. Choose the material and enter the estimated quantity requested by the form. Estimates do not earn points.
2. Enter a written address or landmark that a collector can follow.
3. Use the location button and allow browser permission, or click the map to choose a pin manually.
4. Optionally attach a supported photo, then submit the request.
5. Follow the request's status from available through collection and verification.

If GPS fails, check the browser's site permissions and device location settings. A manual pin can still be used. A request saved with only a written location has no map position. Collector location is the last shared snapshot; it does not refresh continuously.

## Collect pickups

Apply to become a collector and wait for administrator approval. In the collector dashboard, inspect available requests, capture your location when useful, accept a pickup, and mark yourself on the way. After collection, enter the actual weight in kilograms. An administrator must verify it before the user receives points.

## Verify and fulfil rewards

Administrators review collected pickups and use **Verify + reward**. This credits points through the database and requests a Devnet receipt in the background. If the receipt fails, use **Retry Solana receipt** on the verified request. Retrying does not award points again.

Admins also review collector applications and pending reward requests. Fulfilment requires the team's real-world delivery process; marking a reward fulfilled is not an automatic airtime or cash transfer.

## Points and receipts

Users earn 100 points per verified kilogram. Available reward prices come from the server catalog. Requesting a reward reserves the points; a rejected request returns them once. Check the dashboard balance and history for updates.

Open a verified pickup's receipt or Solana link to inspect its blockchain record. Explorer must be set to **Devnet**. The record represents BottleUp's authorized attestation and uses test SOL. It is not a cryptocurrency payment or a Mainnet record.

Bank details can be saved, edited, and removed, but are not bank-verified. Cash withdrawals are not implemented.

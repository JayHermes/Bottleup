# Nigeria's Recycling Value Chain

A simplified Nigerian plastic recycling chain is:

**Plastic producers → manufacturers/packaging companies → consumers → collection → sorting & processing → recyclers/manufacturers → new products**

Around this chain are government agencies, producer responsibility organisations, informal collectors, businesses, community groups and other intermediaries.

UNIDO's Nigerian value-chain research similarly identifies producers, packaging companies, distributors, retailers, collectors and recyclers as interconnected participants. [UNIDO](https://www.unido.org/sites/default/files/unido-publications/2022-12/Plastic-value-chain-in-Nigeria.pdf)\
\
Bottle Up's position

Bottle Up does not need to own every part of this chain.

Its role is to strengthen the connection between:

**plastic waste → collection → verification → recycling market**
